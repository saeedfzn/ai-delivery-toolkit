# Story template

```markdown
**Story: <short outcome-focused title, max 10 words>**

As a <user type>, I want <capability>, so that <benefit>.

**Acceptance criteria**
1. Given <context>, when <action>, then <observable result>.
2. Given <context>, when <unhappy path>, then <clear error or empty state>.
3. (UI only) Given I use a keyboard or screen reader, when <action>, then <accessible behaviour>.

**Notes**
- Out of scope: <anything explicitly excluded>
- Dependencies: <other teams, services, approvals, or "None known">
- Key / points / owner: TBC
```

## Quality checks before returning

- [ ] The "so that" states a real benefit, not a restatement of the "I want".
- [ ] Every criterion can be shown as passed or failed by a tester.
- [ ] At least one unhappy path is covered.
- [ ] No invented keys, dates, points or names.
- [ ] Open questions are listed separately.
